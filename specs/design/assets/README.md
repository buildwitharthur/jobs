# Assets de identidade visual

Catálogo dos recursos vetoriais usados pela interface e pelo protótipo.

| Arquivo | Função |
| --- | --- |
| [favicon.svg](favicon.svg) | Favicon simplificado para tamanhos pequenos, entre 16 e 32 pixels. |
| [icon-maskable.svg](icon-maskable.svg) | Ícone maskable de 512 × 512 para PWA ou atalhos, com fundo até as bordas e símbolo dentro da área segura. |
| [logo-mark.svg](logo-mark.svg) | Símbolo colorido quadrado da identidade, inspirado nas colunas e cards do kanban. |
| [logo-mark-mono.svg](logo-mark-mono.svg) | Versão monocromática do símbolo, baseada em `currentColor`, para contextos de uma única cor. |
| [logo.svg](logo.svg) | Assinatura horizontal colorida para uso sobre fundos claros. |
| [logo-on-dark.svg](logo-on-dark.svg) | Assinatura horizontal preparada para uso sobre fundos escuros. |

As regras de aplicação, tamanhos e restrições da identidade estão em [../design.md](../design.md#logo-e-favicon). As cores utilizadas são definidas em [../design.md](../design.md#cores).
