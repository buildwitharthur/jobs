# Documentação de design

Índice das decisões visuais, comportamentos da interface, recursos gráficos e protótipo.

## Arquivos

| Arquivo | Função |
| --- | --- |
| [design.md](design.md) | Define o design system: layout, espaçamento, elevação, formas, movimento, componentes, estados, responsividade e uso da identidade visual. É a fonte da verdade de cores (tema escuro por padrão e tema claro), fontes e ícones (Lucide). |
| [ui.md](ui.md) | Especifica navegação, telas, interações, rotas consumidas, critérios de aceite e comportamentos globais da interface. |
| [assets/README.md](assets/README.md) | Cataloga os arquivos de logo, símbolo, favicon e ícone de aplicativo. |
| [prototype/README.md](prototype/README.md) | Descreve os arquivos e dependências do protótipo navegável. |

## Relação entre os documentos

- `design.md` define os valores visuais (cores, fontes, ícones) e os transforma em regras e componentes.
- `ui.md` aplica os componentes e comportamentos às telas dos módulos.
- `assets/` contém a identidade visual usada pela interface.
- `prototype/` demonstra visualmente as decisões documentadas.
