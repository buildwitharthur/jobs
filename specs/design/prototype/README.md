# Protótipo da interface

Esta pasta reúne a implementação estática usada para demonstrar as telas e interações descritas em [../ui.md](../ui.md), seguindo o design system de [../design.md](../design.md).

## Arquivos

| Arquivo | Função |
| --- | --- |
| [index.html](index.html) | Estrutura principal do protótipo: navegação, área de conteúdo, painel lateral, modal, toasts e área de arrastar PDF. Também carrega a fonte Inter e os assets de identidade visual. |

## Dependências referenciadas

O `index.html` referencia `index.css` para os estilos e `main.js` para navegação, dados de exemplo e interações. Esses dois arquivos não estão presentes atualmente nesta pasta, portanto o protótipo não funciona de forma completa apenas com os arquivos versionados aqui.

O favicon e o logo são carregados de [../assets/](../assets/README.md).
